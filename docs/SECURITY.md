# Security Notes

## 默认安全边界

1. 仅监听 `127.0.0.1` / `localhost`。
2. 仓库不包含固定 Token、账户号、Cookie、券商地址或用户标识。
3. 未设置 Token 时，每次 QMT 启动随机生成会话 Token，并打印到本机 QMT 控制台。
4. 交易默认关闭。
5. Full 版提供请求限流、Body 大小限制、CORS Origin 白名单、单笔数量/金额上限和幂等键。

## 不要这样部署

- 不要直接把端口暴露到公网。
- 不要把 Token 写进公开仓库、截图或文章。
- 不要为了远程访问把 `127.0.0.1` 改成 `0.0.0.0` 后裸奔。
- 不要把浏览器测试页部署到不受信任站点再允许任意 CORS Origin。

## 远程访问建议

如确有远程需求，优先通过系统级 VPN / SSH 隧道把远端映射到本机回环地址，而不是修改桥接服务本身的监听边界。

## 实盘前检查

- 券商是否允许当前 QMT/程序化交易权限；
- 程序化交易报告是否完成；
- 模拟账户是否覆盖断网、重复请求、超时后重试、撤单失败、部分成交；
- `QMT_BRIDGE_MAX_ORDER_QTY` 和 `QMT_BRIDGE_MAX_ORDER_VALUE` 是否符合账户规模；
- 外部策略是否为每笔交易生成稳定的幂等键；
- 是否有独立的总仓位、单票仓位、日内损失等上层风控。

本项目的单笔数量/金额限制只是最后一道技术护栏，不能替代完整交易风控。
